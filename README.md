# REST API Project

## About This Project
This is a simple REST API project developed to understand backend development and basic DevOps workflow.  
It helps in learning how APIs work, how Git/GitHub is used, and how projects are managed in a real development environment.

---

## Technologies Used
- Node.js / Python
- Express / Flask
- Git & GitHub

---

## What This Project Does
- Creates basic REST API endpoints
- Handles simple GET and POST requests
- Demonstrates Git workflow (commit, push, pull)
